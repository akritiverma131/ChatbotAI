
# ChatbotAI

ChatbotAI is a Python-based chatbot project that allows users to interact with a chatbot through a simple and user-friendly interface.

## Features

- Simple graphical user interface
- Natural Language Processing using NLTK
- Local knowledge base
- Similar question matching
- Remembers user's name
- Remembers college name
- Chat history
- Permanent memory using JSON
- Thinking effect
- Time response
- No external AI API required

## Technologies Used

- Python
- Tkinter
- NLTK
- JSON
- NLP
